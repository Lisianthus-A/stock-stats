# 股票模拟交易系统

本地运行的股票模拟交易工具。录入买入/卖出记录，自动统计当前持仓、总体盈利百分比与盈亏数，
并针对个股展示已持股时间。数据全部保存在本机 `stats.db`，不联网、不上传。

## 快速开始

1. 双击 `start.bat`
2. 浏览器会自动打开 `http://127.0.0.1:8765/`
3. 在「交易流水」页录入数据
4. 关闭黑色命令行窗口即停止服务

> 需要电脑上装有 Python 3.10+（仅使用标准库，无需 `pip install` 任何东西）。
> 若 8765 端口被占用，会自动顺延到 8766、8767…，以命令行输出的地址为准。

## 功能

| 页面 | 内容 |
| --- | --- |
| **总览** | 总体盈利百分比、**累计收益（复利）**、盈亏数、总买入成本、胜率、盈亏比、平均持有时间、最佳/最差单笔、个股盈亏排行 |
| **当前持仓** | 每只持股的成本价、建仓日、**已持股时间**、未平仓笔数、该股已实现盈亏；可展开查看每笔买入的独立持股天数 |
| **交易流水** | 录入 / 编辑 / 删除交易，支持代码联想与搜索筛选 |
| **已平仓明细** | 每一笔买入与卖出的配对结果、盈亏、盈亏率、持有天数，可按股票与盈亏方向筛选并汇总 |

## 录入字段

- 股票代码
- 股票名称（输入已有代码会自动带出名称）
- 日期（年月日，默认为今天）
- 价格
- 备注（可选）

## 计算规则

### FIFO 先进先出配对

同一只股票多次买入、多次卖出时，按日期先后顺序 **1 笔买入对应 1 笔卖出**：

```
买入 A 10.00 (1月1日)  ──┐
买入 A 20.00 (2月1日)  ──┼── FIFO 依次核销
卖出 A 40.00 (4月1日)  ──┘  → 配对 1: 10.00 → 40.00
卖出 A 50.00 (5月1日)  ──┐
                         └── 配对 2: 20.00 → 50.00
```

同一天录入多笔时，按录入先后顺序配对。

### 盈亏口径

| 指标 | 公式 |
| --- | --- |
| 单笔盈亏 | 卖出价 − 买入价 |
| 单笔盈亏率 | (卖出价 − 买入价) ÷ 买入价 × 100% |
| **总体盈利百分比** | Σ单笔盈亏 ÷ Σ配对交易的买入价 × 100% |
| **累计收益（复利）** | 见下方说明 |
| 胜率 | 盈利笔数 ÷ 已平仓总笔数 × 100% |
| 盈亏比 | Σ盈利金额 ÷ \|Σ亏损金额\| |
| 持有时间 | 卖出日 − 买入日；持仓中为 今天 − 买入日 |

### 累计收益（复利）

以 1 为初始值，按**平仓时间先后**把每笔平仓的收益率连乘，最后 ×100% 转成百分比：

```
累计收益 = [ (1 + 收益率₁) × (1 + 收益率₂) × … × (1 + 收益率ₙ) ] × 100%
```

例：三次平仓收益率为 +100%、+100%、−50%
→ `1 × 2.00 × 2.00 × 0.50 = 2` → **200%**

**这是「本金倍数」口径，请注意：**

- 单笔 −10% 会显示为 `90%` 而不是 `−10%`；亏损表现为数值低于 100%，不会出现负数。
- 该指标与「总体盈利百分比」可能差异极大，甚至方向相反。上例同一批交易，
  累计收益是 **200%**，而总体盈利百分比是 **−25%**。两个数字各有用途，建议同时看。
- 复利结果与交易**顺序无关**（乘法满足交换律），但依赖每一笔的收益率。
- 由于不记录股数，这里假设每笔交易投入相同金额，是简化模型。

**重要说明：**

1. 本系统 **不记录股数**，因此「盈亏数」是 **每股价差**（单位：元/股），不是资金盈亏金额。
   例如 10.00 买入、12.00 卖出，该笔盈亏数为 `+2.00`，盈亏率 `+20%`。
2. **持仓中的股票不计入总盈亏**。持仓按买入成本价展示，只统计已平仓（已实现）盈亏；
   累计收益同样只连乘已平仓交易。
3. 若某笔卖出早于该股票最早的买入记录（通常是日期录错），系统会给出警告，
   该笔卖出无法配对、不计入统计，但数据仍会保留。

## 数据存储

- 数据文件：与本程序同目录的 `stats.db`（SQLite）
- 备份：直接复制 `stats.db` 即可（建议先关闭服务再复制）
- `stats.db` 已加入 `.gitignore`，不会被误提交

## 命令行参数

```powershell
python server.py                 # 启动并自动打开浏览器
python server.py --no-browser    # 不自动打开浏览器
python server.py --port 9000     # 指定起始端口
python server.py --verbose       # 打印访问日志
```

## 目录结构

```
stock/stats/
├── start.bat          # 双击启动
├── server.py          # HTTP 服务 + REST API
├── core.py            # FIFO 配对与统计逻辑（纯函数）
├── test_core.py       # 核心逻辑单元测试
├── stats.db           # 数据文件（自动创建）
└── web/               # 前端页面（原生 HTML/CSS/JS，无需构建）
```

## API

| 方法 | 路径 | 说明 |
| --- | --- | --- |
| GET | `/api/trades` | 全部交易记录 |
| POST | `/api/trades` | 新增交易 |
| PUT | `/api/trades/{id}` | 修改交易 |
| DELETE | `/api/trades/{id}` | 删除交易 |
| GET | `/api/summary` | 持仓 + 配对 + 统计（可用 `?as_of=YYYY-MM-DD` 指定基准日） |

`/api/summary` 的 `stats` 中包含 `cumulative_return`（累计收益百分比）与
`cumulative_factor`（本金倍数原始值，例如 `2.0`）。
